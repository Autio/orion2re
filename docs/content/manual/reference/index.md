# Manual: Reference

Use these pages when you need to look up a control or setting, solve a problem,
or find instructions for a particular way of playing.

- [Keyboard shortcuts](keyboard-shortcuts.md) lists controls that are not always
  shown on screen.
- [Settings reference](../../generated/configuration/index.md) lists the current
  configuration settings, their defaults, and their allowed values.
- [Using mods](../legacy-modding/index.md) explains how to install, enable,
  disable, and troubleshoot mods.
- [Multiplayer](../multiplayer.md) explains how to host, join, resume, and recover
  a network game.
- [Internal debugger](../advanced-tools/debugger.md) describes the optional
  testing and experimentation tool and its risks.
- [Acknowledgements](acknowledgements.md) records the manual's provenance and
  credits the people who contributed to the original game, the 1.50 project,
  and the version 2.00 restoration.
- [Third-party software](third-party-software.md) credits the libraries and
  scaler implementations used by version 2.00.
